# Neural Command Center Design System

This system defines the visual and interactive language for the EliteHuman "Neural Command Center" holographic interface. It transitions the product from a traditional 2D dashboard to a spatial, depth-based OS.

## Source Materials
- `src/styles/tokens.css`: Base color palette and spacing.
- `src/styles/glass.css`: Glassmorphism and blur specifications.
- `src/dashboard/index.jsx`: 3D volume and lighting configuration.
- `src/dashboard/components/HolographicPanel.jsx`: Additive blending and material logic.

## System Overview
The system is anchored in "Holographic Materiality"—the idea that UI elements are projected light rather than solid surfaces. This is achieved through additive blending, depth-based opacity, and a strict cyan-on-obsidian palette.
